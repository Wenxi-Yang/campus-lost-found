校园失物招领管理系统

统一发布失物与招领信息，支持查询、招领人确认和管理员审核，保留可追踪的处理记录。

这是项目介绍页。此页面不提供注册、登录或共享数据库功能。完整业务系统需要将Java后端与MySQL部署到服务器后使用。

主要功能

  • 游客浏览与中文关键词、分类、地点、时间范围筛选
  • 学生发布与个人中心、认领证明和招领人确认
  • 管理员用户维护、认领审核、分类公告和统计
  • 公告关联管理员、物品及分类，并按有效期展示

工程组成

frontend为Vue2前端；backend为Spring Boot后端；database为SQL；release为完整WAR；提交材料包含设计、测试、部署、用户手册和展示PPT。

技术环境

JDK 8 · Spring Boot 2.7.14 · MySQL 8 · Vue 2 · Element UI
