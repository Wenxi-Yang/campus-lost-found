# 部署与维护

## 1. IDEA 与开发运行

按照根目录 README 设置 JDK8、Maven3、Node14。根目录 pom.xml 聚合 backend。IDEA 共享配置 Backend-Demo 和 Backend-MySQL 工作目录都为 backend；若模块名与 IDEA 导入结果不同，在运行配置中选择实际包含 Application 的模块。

开发后端 8081，前端 npm run serve 监听 127.0.0.1:8080，Vue 代理/api。打包后的 8081 包含前端，使用 Hash 路由，无需额外路由重写。

## 2. MySQL 初始化

Workbench 执行 database/init-mysql.sql。启动前在同一个 CMD 窗口设置 DB_USERNAME、DB_PASSWORD、ADMIN_PASSWORD。数据库存在才可启动；表结构也会由应用按 schema.sql 检查创建，不会删除已有数据。

ADMIN_PASSWORD 只初始化首个管理员，不会重置已存在管理员。不要把演示口令用于正式环境。管理员创建后可移除启动环境中的 ADMIN_PASSWORD 变量。修改 MySQL 登录密码时同步更新运行环境变量。

## 3. 打包和运行

根目录 build.cmd 安装锁定的 npm 依赖，构建 Vue，复制到 backend/src/main/resources/static，执行 mvn package（含测试），最终输出 release/campus-lost-found.war。

- 双击 start-demo.cmd：独立 H2 文件数据库，仅本地演示。
- CMD 中设置连接变量后执行 start-mysql.cmd：MySQL8 正式存储。
- WAR 可用 java -jar 运行，也可作为 ROOT.war 放入 Tomcat9。不要同时运行两份服务占用 8081。

前端访问绝对路径/api，因此外部 Tomcat 必须以根应用 ROOT 部署。若需要子目录部署，要同时修改前端 API 基路径及代理配置，当前交付默认根应用。

## 4. Nginx 反向代理示例

```nginx
server {
    listen 80;
    server_name your-campus-domain;
    location / {
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

独立服务器建议用 HTTPS，只向内网开放 MySQL。HTTPS 下设置 JWT_COOKIE_SECURE=true。该作业没有邮箱/SMS、图片上传或外部身份认证功能，勿把课程系统当作正式校务身份认证。

## 5. 备份恢复

MySQL 使用 Workbench 的 Data Export / Data Import 进行备份恢复，停机维护前导出 campus_lost_found。H2 演示数据库先停止应用，再备份 backend/data 整个目录。不要在 H2 运行时直接覆盖数据库文件。

恢复后确认管理员、物品数量、申请状态及公告有效期。数据库 timestamps 统一以 Asia/Shanghai 使用，部署机器保持正确时间。

## 6. 常见问题

- 8081 端口占用：停止已运行的旧进程，或设置 SERVER_PORT 并同步前端开发代理。
- Access denied：检查 MySQL 账号、密码和权限，命令与环境变量须在同一窗口。
- Unknown database：先执行初始化 SQL。
- 首次提示 ADMIN_PASSWORD：设置至少 8 位初始管理员密码再启动。
- npm 下载慢：可按网络条件配置镜像；项目锁定依赖，使用 npm ci。Maven 镜像在.mvn/settings.xml 中。
- 修改 Vue 但 8081 没变化：8081 使用已打包页面；开发看 8080，或重新执行 build.cmd。
- 404 静态页面：确认使用 release 中的完整 WAR 或已构建并复制 static 目录。
- IDEA .run 配置未显示：直接在 Application.java 右键运行，设置 profile 和 backend 工作目录即可。
- 公告未展示：检查启用开关、发布时间、生效时间、截止时间和电脑时钟。

## 7. 验证边界

自动接口测试采用独立 H2 内存库；演示启动验证采用 H2 文件库。实际 MySQL8 连接和外部 Tomcat/Nginx 部署须在提供真实连接信息的目标环境再次验证。

## 8. JWT 与旧库补充

默认启动随机 JWT 签名密钥，重启需重新登录。需固定时设置 JWT_SECRET 为 Base64 编码的至少 32 随机字节密钥；禁止把密钥写入源码。campus_token Cookie 具有 HttpOnly 及 SameSite=Lax。退出撤销列表为单实例内存状态；多实例部署需共享撤销存储，当前定位为单实例课程作业。

已有数据库启动时由 SchemaUpgrade 补齐认领确认字段，不删数据；已处理旧申请标记 legacy。无需重复运行手动 ADD COLUMN 脚本。升级前仍建议用 Workbench 导出备份。BCRYPT_STRENGTH 默认 10，成本按 2 的 cost 次方增长。
